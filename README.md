# ⚡ CYBORG // Future Meets Humanity

A futuristic cyborg-themed landing page that merges technology and humanity. Built with a sleek neon blue and silver color palette, metallic gradients, circuit patterns, holographic HUD effects, interactive diagnostics, and a sci-fi audio synthesizer.

---

## 🌟 Key Features

1. **Hero Section**:
   - **Glowing Cyborg Centerpiece**: Photorealistic visual blending human facial anatomy with titanium skull plating, fiber optics, and glowing blue circuits.
   - **Holographic HUD Framework**: Rotating radar sweep, coordinate rings, target brackets, and real-time biometric telemetry widgets.
   - **Bold Headline**: *“Future Meets Humanity”* with metallic silver gradients and neon blue glowing typography.
   - **Prominent "Explore Now" Call-to-Action**: Neon-pulsing button with angular cyber cutouts and animated glow.
   - **Live Telemetry Counters**: Dynamic counting metrics for synaptic latency (0.12ms), neural cohesion (99.98%), and muscular torque (12.4x).

2. **Interactive Canvas Circuit Background**:
   - High-performance HTML5 Canvas rendering floating data packets traveling across circuit-inspired traces.
   - Dynamic mouse reactivity (ambient data links connect to the cursor in real time).

3. **Audio-Synthesized Sci-Fi UI**:
   - Built-in Web Audio API synthesizer emitting subtle sci-fi clicks, mode activation sweeps, and transmission confirmation chimes.
   - Prominent header toggle (`[SFX: OFF] / [SFX: ON]`), muted by default to respect user comfort.

4. **About Section ("The Human-Machine Synthesis")**:
   - Deep narrative exploring the fusion of organic intuition with synthetic computing.
   - High-tech comparison cards with metallic borders and glowing indicators.
   - 3 Transhumanist Pillars: Neural Autonomy, Titanium Resilience, and Adaptive Evolution.

5. **Features Section ("Augmentation Architecture")**:
   - 6 metallic-gradient cards with custom glowing neon SVG icons:
     - *Synaptic Neural Core*
     - *Nanosteel Skeleton*
     - *Quantum Spectral Optic HUD*
     - *Sub-Dermal Bioreactor*
     - *Cryo-Adaptive Plating*
     - *Quantum Neural Firewall*
   - Real-time 3D perspective mouse tilt with specular highlights.

6. **Interactive Modular Cyborg HUD ("Operational Console")**:
   - Interactive system mode switcher:
     - `COMBAT OVERDRIVE`
     - `STEALTH RECON`
     - `QUANTUM ANALYSIS`
     - `SYNAPTIC HARMONY`
   - Real-time reactive gauges for Power Core, Synaptic Synchrony, Kinetic Torque, and Heat Dissipation with live terminal output log.

7. **Contact / Neural Uplink Section**:
   - Encrypted transmission terminal with fields for Operative ID, Neural Frequency (Email), Augmentation Architecture, and Encrypted Message.
   - Live simulated holographic transmission sequence with 4096-bit key generation and confirmation tokens.

8. **Fully Responsive**:
   - Optimized for mobile phones, tablets, laptops, and ultra-wide displays.
   - Mobile cyber slide drawer navigation.

## 🚀 How to Launch

### Method 1: Direct Browser
Simply double-click [`index.html`](file:///c:/Projects/cyborg/index.html) to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Method 2: Local HTTP Server
Run with npm:
```bash
npm start
```
Or with Python:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
